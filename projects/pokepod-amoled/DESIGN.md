# PokePod AMOLED Design

## 呼吸胶囊

PokePod 使用“呼吸胶囊”视觉世界：纯黑 AMOLED 是空间，胶囊像一个安静的
生命体悬浮其中。薄膜状轮廓表达待机，真实麦克风音量驱动录音时的呼吸与展开；
青瓷绿承接 Android 的录音强调色，柔和蓝紫只表示 Mac 语音输入，琥珀和珊瑚
分别保留给等待与故障。

首屏固定为首页，横向顺序为“首页 → 胶囊 → 设备”。首页只保留顶部状态、中央
语音胶囊和 USB 连接后出现的 Mac 语音输入。底部使用三个可点击的图形导航目标，
同时保留横向滑动。

界面层级固定为：

1. 24–32 px 的当前任务或正文；
2. 16–24 px 的动作名称；
3. 12–16 px 的时间、连接和恢复提示。

固定界面汉字允许放大为 24/32 px；任意胶囊正文优先使用可滚动的大字阅读。
控制依靠图形、位置、文字和明暗共同表达，状态不只依赖颜色。

页面不使用同等权重的彩色矩形阵列。首页中央胶囊是唯一高强调动作；Mac 输入
位于次级操作轨；胶囊列表使用连续文字行；设备页使用状态行、开关和按需展开的
诊断信息；详情页让正文占据中心，播放为主要动作，收藏、归档和重试进入紧凑
操作坞。

动效只集中在录音这一刻：音量驱动胶囊膜、对称声纹与计时，每秒约 8 帧，使用
局部离屏缓冲避免闪烁。页面和状态切换先在 PSRAM 离屏完成再提交到屏幕。
USB UAC 工作时继续让音频优先，动画可以暂停，实体键行为不受影响。

手机配网页延续同一套纯黑、青瓷绿、连续信息面的视觉语言。网络与腾讯转写分为
两个编号步骤；附近网络扫描是默认路径，手工 SSID 收进按需展开区；已保存密钥
只显示状态，不回显内容。所有输入保持 16 px 以上，页面由浏览器根滚动容器承载，
软键盘出现后仍能连续滚动和自动定位当前字段。

三端共享胶囊图形、对象命名、正文优先级、状态与恢复语义；Android、Mac、
PokePod 各自保留原生布局与交互代码。PokePod 的维护边界限定为主题令牌、图标、
中文渲染和页面组合，不把嵌入式像素坐标扩散到共享协议。
