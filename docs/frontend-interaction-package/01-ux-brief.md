# UX Brief

## 核心任务模型

### 无线微信输入

用户在 Mac 输入框前按住 PokePod 的微信入口或 BOOT。设备只在 `Voice.app` 已就绪后锁定长按，立即采音并预缓冲；Mac 在音频可输出后按下 Option+Z，松手后排空尾部、释放按键并恢复原麦克风。连接中断时 500 ms 内恢复。

### 本地语音胶囊

用户轻触语音胶囊入口开始录音，再次轻触停止。停止后胶囊立即进入列表，腾讯转写在后台推进；用户可继续浏览和使用无线输入。新本地录音在转写完成或安全重试前暂缓。

### 轻量整理

用户进入胶囊页，通过标题范围选择收件箱、收藏、待转写、失败、归档或回收站；长按条目 500 ms 进入多选，批量收藏、归档或移入回收站。删除提供五秒撤销，回收站可恢复。

### 配对与恢复

用户在设备页进入两分钟配对模式。Mac 应用逐项显示蓝牙、BlackHole 和辅助功能是否就绪；断线可以重连，音频异常可以恢复原麦克风，设备可以忘记已绑定 Mac。

## 体验原则

- 一个时刻只突出一个主要状态。
- 所有副作用动作在点击/滑动/长按仲裁完成后启动。
- 运行中状态保持局部、持续、可退出。
- 失败必须保留数据并给出下一步。
