# 路由与布局

## routes

- `pod-home-route`：设备启动进入首页；向左进入胶囊，向右进入设备；录音和无线长按锁定根页面滑动。
- `pod-capsules-route`：从首页横滑进入；标题打开范围层；条目轻触进详情，长按进多选；返回保持范围和滚动位置。
- `pod-device-route`：从首页横滑进入；无线语音行展开配对/忘记/连接详情；子页覆盖时底层命中关闭。
- `voice-menu-route`：Mac 菜单栏图标打开；点空白或再次点图标关闭；正在输入时保持状态可见。

## 368×448 布局

- 顶部状态区 48 px；内容安全边距 24 px；底部分页只占 12 px。
- 首页两个动作卡各 142 px 高，间距 12 px，图标与文字使用同一纵向中心线。
- 列表行 68 px，leading 32 px、content 弹性、accessory 72 px。
- 多选操作栏覆盖底部 72 px；列表内容增加等量安全尾距。

## macOS 菜单栏布局

面板 360×520；顶部总状态、三项依赖检查、当前设备/连接指标、恢复动作和退出。输入期间禁止隐藏关键恢复状态。
