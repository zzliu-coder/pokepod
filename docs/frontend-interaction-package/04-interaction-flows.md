# 交互流程

## 对象动作

### 首页卡片与根滑动

触摸开始只登记候选。横向位移达到 32 px 且横向优势超过纵向 1.35 倍时锁定根滑动并取消卡片；位移保持在 12 px 内且抬起时执行轻触；微信卡持续 280 ms 后进入按住候选，Voice ready 且达到阈值才占用麦克风。

### BOOT

- BLE Voice ready：按下 280 ms 后开始无线会话，松开结束；提前松开只给出“请按住说话”。
- BLE Voice 未就绪：短按开始/停止本地胶囊。
- 本地录音中：BOOT 结束本地录音。

### 胶囊列表

垂直位移 12 px 后锁定滚动；保持 500 ms 且位移小于 10 px 时进入多选。多选后轻触切换选择，横向根切页关闭。正在转写条目可以查看，不能进入可变更选择。

### 删除与恢复

删除移动到 `.trash`，显示五秒撤销。撤销恢复原目录；目录无效或冲突时回 Inbox。回收站“恢复”使用相同规则。批量移动预检全部目标，失败回滚已完成项。

### 无线异常

BLE 断线、400 ms 无音频、应用退出或 CoreAudio 错误都会释放 Option+Z 并恢复输入设备。用户手动把默认输入换走 BlackHole 后，应用记录新选择并停止覆盖。
